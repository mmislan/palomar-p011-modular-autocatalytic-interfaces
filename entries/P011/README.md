# MAF composition criteria, exact enumeration of child-selection autocatalytic cores, and degradation regions of linear diluted source networks

How does the maximum amplification factor (MAF) compose, can child-selection autocatalytic cores be recovered from ordinary cores, and how does species-specific degradation decide linear diluted growth? For networks with nonnegative inputs and attained MAFs, adding a reaction with nonnegative input, aggregating species by a nonnegative matrix, or shared-species coupling raises the MAF (for coupling, above both component MAFs) exactly when, at some threshold q above the old value, the result has no strict price: a nonnegative species price p with p·output < q·(p·input) in every reaction. A block direct sum attains the larger component MAF. For N1 (A → B, B → 4A) and N2 (A → 4B, B → A), N1, N2 and N1‖N1 have MAF 2 but N2‖N1 has MAF 4, so component MAFs do not determine coupled MAFs. Given a complete list of ordinary-core anchor matchings, each unique on its vertex set, toggling anchors along disjoint alternating boundary paths and filtering with a certified rational semipositivity test returns exactly the child-selection cores, the minimal autocatalytic matching edge sets. Such a test exists for every finite network: by an exact rational Gordan alternative, every matching with at least one species has a rational primal or dual certificate, and matchings with no species are never autocatalytic. For A → 2A all hypotheses hold and the enumerator returns the one-edge core. For the linear diluted source matrix A of nonnegative unary reactions with irreducible source graph and degradation d ≥ 0, A − diag(d) has positive, zero or negative real spectral bound exactly when d is componentwise strictly below, equal to, or strictly above the projective degradation (Av)_i/v_i of some positive v. For Metzler A, degradation on actuated species alone yields positive v with (A − diag(d))v componentwise negative exactly when the unactuated block has such a v.
